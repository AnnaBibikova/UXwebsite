Jira via Codex Connector

Use it for: finding related work, summarizing tickets, drafting issues from research, and checking decisions in Confluence.

  1. In Codex, open Plugins or Connectors.
  2. Find Atlassian Rovo, install it, and sign in to your Atlassian account.

Pendo MCP via Codex Connector

Use it for: connecting Codex to Pendo so you can ask questions about usage and use Pendo tools through an authenticated OAuth connection. MCP is the right starting point when you want Codex to work with Pendo interactively. An integration key is for a separate API integration or automation.

Set up Pendo MCP

  1. In Codex, open Settings and search for MCP Server.
  2. Open the MCP tab, select Add, then Add MCP Server.
  3. Enter Name: Pendo. Choose Type: Streamable HTTP.
  4. In Server URL, use the regional MCP URL that matches the site you use to sign in to Pendo. If you sign in at app.pendo.io, enter https://app.pendo.io/mcp/v0/shttp.
  5. Save the server and select Authenticate. Sign in to Pendo and authorize the connection.

You don’t need an integration key for MCP setup or to try creating guides. Start with the OAuth connection you added.

Integration keys are for separate API projects

Create an integration key later only if you have a specific API integration in mind.

  • Description: give it a clear purpose, such as Pendo API – nightly analytics export.
  • Allow Write Access: leave this unchecked unless the integration must change data in Pendo. Read-only is the safer default.

Important: Pendo says an integration key can access data across all apps in the subscription. Treat it like a password and store it in a secure secrets manager.

Chrome DevTools MCP via Codex Connector

Use it for: inspecting a page, checking console errors, understanding layout, and investigating performance or accessibility issues while working in Codex.

  1. Make sure Node.js and npx are available.
  2. In Terminal, run codex mcp add chrome-devtools -- npx -y chrome-devtools-mcp@latest.
  3. Restart Codex and confirm it appears in codex mcp list. Approve browser access only for sites you’re allowed to inspect.

Chrome DevTools MCP setup guide

Try: “Inspect this page at desktop and mobile widths. Report the three biggest usability issues with screenshots. Don’t edit anything.”
Figma MCP with Codex Connector

Use it for: sharing Figma frames, components, variables, and layout details with Codex so it can help implement or review a design.

  1. In Codex, open Plugins, find Figma, and select Install Figma.
  2. Allow access to the Figma account you want to use.
  3. Copy a link to the specific Figma frame and include it in your Codex request. Start with one frame and name the codebase components or rules it should follow.

Skills and plugins

Reusable workflows and extensions for tools your team uses.

How to add or use a team skill How-to
  1. Ask Codex to create a skill for one specific workflow, such as “turn interview notes into themes with evidence and open questions.”
  2. Give it a clear name and description, then review its SKILL.md instructions and supporting files.
  3. For a repo-wide team skill, save it under .agents/skills/<skill-name>/SKILL.md, then share it through the repository. For a personal skill, use your Codex user skills folder.
  4. Invoke a skill by name or ask for the workflow it describes. If a teammate adds one, pull the repo changes; Codex should discover the skill automatically.
  5. Add the skill to this library with its link, what it does, when to use it, setup steps, and an example request.

Don’t put credentials or private customer data in a skill. For a reusable team-wide install across different projects, consider packaging it as a plugin.

Starting points for when you’re not sure what to ask.

Make messy feedback usefulPaste de-identified comments. Ask for themes, supporting quotes, counterexamples, and unanswered questions.
Connect signals to actionPair usage patterns with research. Ask what the evidence shows, what it doesn’t show, and what to test next.
Get a second design opinionShare a flow or screenshot. Ask for usability risks, accessibility issues, and specific improvements—ranked by impact.
