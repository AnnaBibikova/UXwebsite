# UX Insights

A simple static GitHub Pages site for capturing UX observations, customer complaints, overheard comments, and ideas. It also includes AI tool setup guides, a team skills guide, and UX examples.

## Notes and privacy

Notes are saved in the browser's local storage. They remain in that browser on that device and are not shared with teammates. Use **Export notes** to save a JSON backup. Clearing browser storage will remove saved notes.

For shared team use, connect the page to a shared data source in a later version. Do not put identifiable customer details or confidential information in a public repository.

## Update the AI tools library

Edit the **AI tools** panel in `index.html` to add or update a guide. Include what the tool is useful for, short setup steps, a link to authoritative instructions, and a sample request. Add team skills with a link, setup notes, and when to use them. The repository is public, so the text and links in the library are public too.

## Publish

The site is served from the `main` branch root using GitHub Pages. It has no build step or external dependency.
